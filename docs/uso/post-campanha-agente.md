# Agente de comentários no post

Seção **Resposta IA** no dialog da postagem (aba lateral ou bloco dedicado).

## Modo de resposta deste post

Select **Modo de resposta** / **Modo nesta publicação**:

| Opção | Efeito |
| ----- | ------ |
| **Seguir global** | Usa **Configurações → Agente de comentários → Modo global** |
| **Pausar nesta publicação** | Iris não responde comentários **deste** post |
| **Automático** | Responde e publica sem revisão |
| **Com aprovação** | Gera rascunho; operador aprova |

Linha **Estado efetivo agora: {label}** mostra o modo calculado.

## Campanha temporária

- **Agente ativo por (dias)** — ex.: `7` limita respostas automáticas aos N dias após publicar. Vazio = sem limite.
- Contador **Expira em X dias** / **Campanha do agente expirada** quando aplicável.

## DM após comentário

**DM após comentário** — envia mensagem privada no inbox quando alguém comenta (API Meta; uma DM por comentário, janela de 7 dias).

Link **Editar persona** abre **Persona** em nova contexto.
