# Comentários — sincronizar e vincular

**Rota:** `/admin/comments` · post selecionado

## Barra de ações do post

| Botão | Função |
| ----- | ------ |
| **Sincronizar** | Puxa comentários novos, mídia e métricas da Meta |
| **Vincular respostas** | Reconcilia respostas já publicadas no Instagram com o Iris |

## Abas do detalhe

| Aba | Conteúdo |
| --- | -------- |
| **Desempenho** | Métricas e insights do post |
| **Comentários** | Thread e respostas |
| **Legenda** / **Resumo** / **Prompt adicional** | Conteúdo editorial |
| **Config** | Modo de resposta deste post |

## Quando sincronizar

- Comentário apareceu no Instagram mas não no Iris (webhook atrasado)
- Após importar post externo
- Antes de revisar métricas em **Desempenho**

→ Saúde dos eventos: [Webhooks](./webhooks.md)
