# Mensagens — escalação e IA pausada

Quando o agente DM detecta caso para humano (**notify_operator**):

1. Cliente é informado que o caso será verificado internamente.
2. Se **Alertas do operador** estiver ligado → email para **Email do operador**.
3. Conversa pode exibir **IA pausada**.

## Destravar

- Botão **Retomar IA** na conversa, ou
- Aguardar **Retomar IA automaticamente após (dias)** configurado em **Configurações → Alertas do operador**

![badge **IA pausada** + botão **Retomar IA**](/docs/images/uso/23-dm-ia-pausada.png)

Configure alertas em [Alertas do operador](./alertas-operador.md).
