# Produtos — cadastro

**Rota:** `/admin/products` · eyebrow **Editorial**

## Lista

- Filtro: **Todos** / **Somente ativos** / **Somente inativos**
- Busca: **Buscar por nome ou slug…**
- **Novo** — cria produto

![split lista + estado "Selecione um produto"](/docs/images/uso/24-produtos-lista.png)

## Criar produto

Dialog **Novo produto**:

1. **Slug** — identificador único (triagem DM)
2. **Nome**
3. **Ativo** — toggle
4. **Criar produto**

## Editar

Painel direito:

- **Descrição curta (Markdown)** — resumo na triagem
- **Descrição longa (Markdown)** — contexto completo para o agente
- **Salvar alterações** / **Excluir produto**

Produtos manuais alimentam o agente mesmo **sem** loja Yampi.

→ [Vínculo Yampi](./produtos-vinculo-yampi.md) · [Lojas — conectar](./lojas-conectar.md)
