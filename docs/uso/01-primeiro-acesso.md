# 01 — Primeiro acesso

**Tempo:** ~3 min · **Para:** quem vai usar o admin Iris

## O que você vai fazer

Entrar no Iris com seu email e, se ainda não conectou, ligar sua conta Instagram ao sistema.

## Passo 1 — Abrir o Iris

1. No navegador, acesse o endereço que o responsável pelo Iris te passou (ex.: `https://iris.suamarca.com/admin`).
2. Você verá a tela de **login**.

## Passo 2 — Login com código por email

1. Digite o **email** autorizado (o mesmo cadastrado pelo administrador).
2. Clique em **Continuar**.
3. Abra sua caixa de entrada e copie o **código de 6 dígitos**.
4. Cole o código e clique em **Entrar**.

**Como saber que deu certo:** você entra no **calendário** (tela principal).

## Passo 3 — Conectar o Instagram (se pedido)

Se no topo aparecer **Conectar Instagram**:

1. Clique em **Conectar** no header.
2. Faça login na conta Instagram da marca.
3. Aceite **todas** as permissões.
4. Volte ao Iris — o **@usuario** deve aparecer no topo.

Se não aparecer o botão de conectar, alguém já configurou ou o servidor ainda não está pronto → veja [Configuração](../configuracao/).

## O que você vê depois de entrar

| Área no menu | Para quê |
| ------------ | -------- |
| **Calendário / Lista / Kanban** | Ver e criar postagens |
| **Comentários** | Ler e responder comentários |
| **Mensagens** | Inbox de DMs |
| **Configurações** | Fuso horário, agentes, notificações |
| **Persona** | Tom de voz do agente de IA |
