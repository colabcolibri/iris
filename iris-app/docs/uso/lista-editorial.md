# Lista editorial

**Visão:** menu **Lista** · eyebrow **Lista editorial**

1. Navegue mês com setas **Mês anterior** / **Próximo mês**.
2. Veja contagem `{n} postagens` do mês.
3. Clique em uma linha/card para abrir o editor.
4. **Nova postagem** — mesmo botão das outras visões.

Use quando o Calendário visual estiver cheio e você quiser lista cronológica compacta.
