# Kanban

**Visão:** menu **Kanban** (a página tem o título interno **Pipeline editorial** — mesma tela)

## Colunas

| Coluna | Conteúdo |
| ------ | -------- |
| **Rascunho** | Posts sem data ou não agendados |
| **Agendado** | Com data/hora futura |
| **Publicado** | Já no Instagram |
| **Falhou** | Erro de publish |
| **Cancelado** | Arraste para área de cancelamento ou ações do card |

![board com as cinco colunas e cards com miniatura](/docs/images/uso/11-kanban-colunas.png)

## Filtro de período

Botão **Período** no topo — presets:

- **Hoje → +15 dias** (padrão)
- **Últimos 30/60 dias**, **Hoje → +30/+60**, **Mês atual**, **Próximo mês**, **Tudo**

Rascunhos sem data planejada **sempre** aparecem.

## Ações rápidas no card

Menu **Ações** do card: desagendar, cancelar, abrir editor.
