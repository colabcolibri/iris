# Navegação no admin

**Para:** qualquer operador · **Rota base:** `/admin`

## Sidebar — grupos do menu

O menu lateral organiza o Iris em áreas de trabalho:

| Grupo visual | Itens | Rota |
| ------------ | ----- | ---- |
| Dashboard | **Calendário**, **Lista**, **Kanban** | `/admin` (mesma rota, visão diferente) |
| Operação | **Comentários**, **Mensagens**, **Webhooks**, **Execuções**, **Fila do agente** | `/admin/comments`, `/admin/messages`, etc. |
| Editorial / catálogo | **Produtos**, **Lojas** | `/admin/products`, `/admin/stores` |
| Lab | **Simulador comentários**, **Simulador DM** | `/admin/agent-simulator`, `/admin/message-simulator` |
| Rodapé | **Configurações**, **Persona** | `/admin/settings`, `/admin/persona` |

![sidebar expandida com todos os itens visíveis](/docs/images/uso/04-sidebar-completa.png)

## Header

| Elemento | Função |
| -------- | ------ |
| Logo + subtítulo **Creative scheduler** | Identidade; clique volta ao calendário |
| Badge **Agente: {modo}** | Modo global do agente de comentários; clique abre **Configurações** |
| Chip Instagram | `@usuario` conectado ou botão **Conectar** |
| Menu da conta | **Testar conexão**, **Trocar conta**, **Desconectar**, **Sair** |
| Seletor de idioma | **Português** / **English** |

## Três visões do calendário

**Calendário**, **Lista** e **Kanban** não são telas separadas — são modos de ver o mesmo pipeline editorial. Alterne clicando no item correspondente na sidebar.
