# Calendário — visão geral

**Para:** operador editorial · **Rota:** `/admin` (item **Calendário** na sidebar)

## Três visões, um pipeline

Calendário, **Lista** e **Kanban** mostram **as mesmas postagens** — só mudam a forma de navegar.

| Visão no menu | Melhor para |
| ------------- | ----------- |
| **Calendário** | Ver o mês, dias com posts, clicar em uma data |
| **Lista** | Scan rápido do mês com contagem de postagens |
| **Kanban** | Acompanhar status editorial por coluna |

Alterne clicando **Calendário**, **Lista** ou **Kanban** na sidebar (todos apontam para `/admin` com visão diferente).

![calendário editorial do mês atual com posts visíveis; sidebar com os três itens destacados](/docs/images/uso/03-calendario-mes.png)

## Elementos comuns

- Botão **Nova postagem** (Calendário, Lista e Kanban)
- Fuso editorial definido em **Configurações → Fuso horário editorial**
- Status possíveis: **Rascunho**, **Agendado**, **Publicado**, **Monitorado**, **Falhou**, **Cancelado**
