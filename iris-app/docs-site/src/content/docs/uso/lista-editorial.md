**Rota:** `/admin` → menu **Lista** · **Para:** quem prefere uma lista cronológica compacta em vez do calendário visual

## O que esta tela mostra

A mesma agenda editorial do [Calendário](/docs/uso/calendario-visao-geral/) e do [Kanban](/docs/uso/kanban-pipeline/), só que em formato de lista, uma linha por post, agrupada por mês. Útil quando o mês tem muitos posts e o calendário visual fica poluído, ou quando você quer escanear título/data rapidamente sem abrir cada card.

## Como usar

1. Use **Mês anterior** / **Próximo mês** para navegar entre meses.
2. O contador `{n} postagens` no topo mostra quantos posts existem naquele mês.
3. Clique em qualquer linha para abrir o editor do post (mesmo dialog usado no Calendário e no Kanban).
4. Use **Nova postagem** para criar um post novo — é o mesmo botão presente nas outras visões.

**Como saber que deu certo:** a lista atualiza imediatamente ao trocar de mês; o post que você editar reflete o novo status assim que você salva.

## Quando usar esta visão em vez das outras

- **Lista**: ler rápido, em ordem cronológica, muitos posts no mês.
- **Calendário**: visualizar distribuição no tempo, ver dias vazios.
- **Kanban**: acompanhar por estágio (rascunho → agendado → publicado).

As três visões mostram os mesmos posts — trocar de visão não move nem duplica nada.
