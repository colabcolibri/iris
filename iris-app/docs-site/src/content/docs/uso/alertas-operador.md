**Rota:** `/admin/settings` · seção **Alertas do operador** (`#operator-notifications`)

Quando o agente de DM escala um caso para humano:

| Controle | Função |
| -------- | ------ |
| **Enviar alertas por email** | Toggle liga/desliga |
| **Email do operador** | Destino dos alertas |
| **Retomar IA automaticamente após (dias)** | Despausa conversa após N dias |

**Salvar** · **Enviar teste** — valida que o email chega.

Relacionado: [Mensagens — escalação](./mensagens-escalacao.md)
