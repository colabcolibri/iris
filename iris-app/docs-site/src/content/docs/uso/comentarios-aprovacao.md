Com **Modo global = Com aprovação** em **Configurações → Agente de comentários**, todos os posts em **Seguir global** geram rascunho antes de publicar.

## Onde revisar pendências

1. **Atividade** → sub-aba **Aprovação** — todos os rascunhos aguardando.
2. Ou dentro de cada post — badge **{n} pendentes**.

Veja também o exemplo de thread com rascunho em [Comentários — responder](/docs/uso/comentarios-responder/).

## Ações

- **Aprovar e publicar**
- **Editar rascunho** → **Salvar** → aprovar
- **Deletar rascunho** — descarta sem publicar

## Modo global Desligado vs. pausar post

| Configuração | Efeito |
| ------------ | ------ |
| **Desligado** (global) | Nenhum post responde automaticamente |
| **Pausar nesta publicação** | Só aquele post fica mudo; os demais seguem o global |

Termos corretos na UI: **Desligado**, **Automático**, **Com aprovação** — não use "silêncio" ou "supervisionado".
