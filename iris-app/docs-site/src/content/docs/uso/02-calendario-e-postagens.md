**Tempo:** ~15 min na primeira postagem · **Para:** operador editorial

## O que você vai fazer

Criar uma postagem com imagem, legenda e horário — e acompanhar até publicar no Instagram.

## Onde fica no admin

Menu lateral → **Calendário**, **Lista** ou **Kanban** (são três visões dos **mesmos posts**).

| Visão | Melhor para |
| ----- | ----------- |
| **Calendário** | Ver o mês e arrastar datas |
| **Lista** | Ordenar e filtrar muitos posts |
| **Kanban** | Acompanhar status (rascunho, agendado, publicado) |

## Passo 1 — Criar uma nova postagem

1. Clique em **Nova postagem** (ou no `+` no calendário).
2. Na janela que abrir:
   - **Imagens:** envie uma ou várias (carrossel).
   - **Legenda:** escreva o texto do post.
   - **Data e hora:** escolha quando publicar (ou deixe rascunho).

**Dica:** o Iris otimiza as imagens automaticamente ao enviar — não precisa redimensionar antes.

## Passo 2 — Escolher o status

| Status | Significado |
| ------ | ----------- |
| **Rascunho** | Salvo no Iris, **não** vai ao Instagram ainda |
| **Agendado** | Publica sozinho no horário escolhido |
| **Publicado** | Já está no Instagram |
| **Cancelado** | Não será mais publicado |
| **Falhou** | Algo deu errado na Meta — abra o post para ver o motivo |

## Passo 3 — Agendar e confirmar

1. Defina **data e hora** no seu fuso (configurado em Configurações).
2. Salve como **Agendado**.
3. No calendário, o post aparece no dia/hora corretos.

**Como saber que deu certo:** perto do horário, o status muda para **Publicado** (o servidor precisa estar online).

## Passo 4 — Editar ou reagendar

1. Clique no post no calendário ou na lista.
2. Altere legenda, imagens ou horário.
3. Salve de novo.

Só edite posts **ainda não publicados** para mudar o que vai ao Instagram. Posts já publicados: o Iris guarda o histórico; alterações no Instagram em si são feitas no app.

## Campanhas com agente nos comentários

Em posts específicos você pode definir:

- **Dias com agente ativo** — por quantos dias após publicar o Iris responde comentários automaticamente.
- **Modo de resposta privada** — se o agente pode chamar o cliente no DM a partir do comentário.

Isso aparece no editor do post quando a funcionalidade está habilitada no seu Iris.

## Problemas comuns

| O que acontece | O que verificar |
| -------------- | --------------- |
| Post ficou **Falhou** | Instagram desconectado (reconecte no header) ou imagem inacessível |
| Não publicou no horário | Servidor Iris offline ou relógio/fuso errado em Configurações |
| Não consigo enviar imagem | Tamanho/formato; tente JPG ou PNG |
