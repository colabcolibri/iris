**Rota:** `/admin/agent-simulator` · menu **Simulador comentários**

## Para quê

Testar respostas do agente de comentários **sem publicar** no Instagram.

## Passos

1. Monte um cenário (post fictício ou real, comentário de exemplo).
2. Execute o harness.
3. Leia o resultado: triagem, rascunho, verificação.

![palco do simulador com resultado à direita](/docs/images/uso/36-simulador-comentarios.png)

## Dicas

- Ajuste **Persona** antes de simular mudanças de tom
- Compare com [Execuções](./execucoes-agente.md) após ir para produção
- Use antes de mudar **Modo global** para **Automático**
