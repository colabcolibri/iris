**Rota:** `/admin/messages`

## Fluxo

1. Conversas com pendências: badge **{n} para responder** ou **Pendente**.
2. Mensagem com **Rascunho IA** — revise texto.
3. **Enviar** / aprovar conforme modo.
4. **Deletar rascunho** — confirma *"Nada será enviado na Meta"*.

Aba **Atividade → Aprovação** — fila centralizada de DMs.

![mensagem com **Rascunho IA** e botões Salvar/Enviar](/docs/images/uso/22-dm-rascunho-ia.png)

## Modo por conversa

Ícone **Configurações da conversa**:

- **Modo de resposta** — herda global ou override
- **Briefing desta conversa** — contexto extra → **Salvar briefing**

→ [Agente de DMs](./agente-dms.md)
