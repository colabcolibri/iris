**Rota:** `/admin/comments` · eyebrow **Operação**

## Layout do hub

Painel esquerdo com duas abas:

| Aba | Função |
| --- | ------ |
| **Publicações** | Escolher post → ver thread de comentários |
| **Atividade** | Fila transversal: aprovações, recentes público, recentes Iris |

Campo de busca: **Buscar legenda ou ID…**

Barra de ações: **Recarregar lista**, **Importar**, **Adicionar**

![hub com aba Publicações, lista de posts, painel direito vazio](/docs/images/uso/15-comentarios-publicacoes.png)

## Fluxo básico

1. Aba **Publicações** → clique em um post.
2. Painel direito: abas **Desempenho**, **Comentários**, **Legenda**, **Resumo**, **Prompt adicional**, **Config**.
3. Responda na aba **Comentários**.

Se a lista estiver vazia → [Importar publicações](/docs/uso/comentarios-importar/) ou aguarde webhook (veja [Webhooks](/docs/uso/webhooks/)).
