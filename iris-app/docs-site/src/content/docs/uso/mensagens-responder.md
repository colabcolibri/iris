**Rota:** `/admin/messages` · conversa selecionada

## Envio manual

1. Selecione conversa na lista.
2. Leia histórico (mensagens do cliente vs. **Marca**).
3. Campo **Escreva uma mensagem…** → **Enviar mensagem**.

![conversa com composer e histórico de mensagens](/docs/images/uso/21-dm-composer.png)

## Responder citando mensagem

**Respondendo a** / **Em resposta a** — cita uma mensagem específica da thread (**Cancelar citação** para voltar ao envio normal).

## Resposta com IA

- **Gerar rascunho com IA** → editar → **Enviar**
- Modo **Com aprovação**: fluxo igual comentários (rascunho antes de enviar)

→ [Aprovação de DMs](./mensagens-aprovacao.md)
